## 📌 About JeikCode

**JeikCode** is a next-generation, high-performance autonomous AI coding agent written from scratch in pure Rust (supporting TUI, WebUI, Desktop Tauri, and background Daemon modes), designed with industrial-grade resilience and efficiency:

- ⚡ **Native Blazing Speed & Minimal Footprint**: Built on an asynchronous pure Rust core with sub-second cold starts and tens of megabytes of resident memory, completely free from Electron bloat.
- 🛡️ **98–99% KV-Cache Hit Rate**: Strict Append-Only prefix stability and core memory preservation (`sacred_floor`), drastically reducing token costs and cutting first-token latency to milliseconds.
- 🗺️ **Native Semantic Code Graph (CodeExplore)**: Deep AST-level call topology and domain-specific bilingual thesaurus for natural business language queries across 12+ mainstream programming languages.
- 🔄 **Protocol & Model Decoupling**: Native support for OpenAI, Anthropic Claude, Google Gemini, Ollama, and compatible custom endpoints with fine-grained inference trajectory controls.
- 🛠️ **Industrial-Grade Self-Healing & Atomicity**: Multi-layered error self-healing, atomic state machine diff patching, and one-click historical checkpoint rollbacks (`undo`).

## 📌 关于 JeikCode

**JeikCode** 是一款基于纯 Rust 打造的次时代原生全能自主 AI 编程智能体（全面支持终端 TUI、WebUI、Tauri 桌面端与后台常驻 Daemon 模式），具备工业级硬核特性：

- ⚡ **原生极速与超低资源占用**：纯 Rust 异步驱动内核，毫秒级冷启动，常驻内存仅数十兆，彻底告别 Electron 架构性能膨胀；
- 🛡️ **98–99% 极致缓存命中率 (KV-Cache)**：严格的追加式（Append-Only）前缀锁定与核心记忆圣地保护（`sacred_floor`），首字毫秒级极速响应，削减 90% 以上 Token 消耗；
- 🗺️ **纯 Rust 原生语义代码图谱 (CodeExplore)**：内置 Tree-Sitter 原生支持 12+ 种主流编程语言，AST 符号拓扑融合领域双语词林，支持直接使用业务自然语言进行整仓双向溯源；
- 🔄 **协议与模型自由解耦**：原生适配主流大模型通信协议（OpenAI、Anthropic Claude、Google Gemini、Ollama 等），支持推理轨迹与流式响应精细调控；
- 🛠️ **工业级自愈与原子状态机保护**：多层错误自愈机制，原子化文件补丁，杜绝并发写冲突，支持历史版本一键撤销（`undo`）回滚。
