## 📌 关于 JeikCode / About JeikCode

**JeikCode** 是一款基于纯 Rust 打造的次时代原生全能 AI 编程智能体（TUI / WebUI / Desktop / Daemon），具备以下工业级特性：

- ⚡ **原生极速 & 超低内存占用**：纯 Rust 异步核心，毫秒级冷启动，常驻内存仅几十 MB，无 Electron 膨胀；
- 🛡️ **98–99% KV-Cache 命中率**：严格 Append-Only 前缀保护与核心记忆神圣保留（`sacred_floor`），大幅削减 Token 消耗；
- 🗺️ **纯 Rust 原生语义代码图谱 (CodeExplore)**：AST 级调用链与业务关键词双向溯源；
- 🔄 **协议与模型自由解耦**：原生集成主流模型协议，支持流式对话与推理轨迹精细调控；
- 🛠️ **工业级自愈与一致性修复**：多层错误自愈机制，原子化文件打补丁，保障复杂项目工程落地。
